# Referensi Tugas Sesi 5 — peta bagian ke berkas

Semua kode di sini adalah **contoh**, bukan jawaban. Yang dinilai adalah kode timmu sendiri:
sebut nama berkas `.vue` dan nama fungsinya di setiap jawaban.

| Bagian tugas | Berkas referensi | Isinya |
| :--- | :--- | :--- |
| **Yang dinilai** — `:key` di komponen list-mu | `02-index-as-key.html` | Demo hidup: toggle `:key="index"` vs `:key="item.id"` |
| Tambahan — lima kegagalan port Vue | `01-kegagalan-klasik.md` | Kode salah + gejala + akar + versi benar |
| Tambahan — stasiun React | `03-stasiun-react.md` | Ringkasan 4 stasiun + template sticky 🟢🟡🔴 |

## Cara pakai

**Soal utama.** Buka `02-index-as-key.html` dengan dobel-klik di browser (butuh internet sekali untuk
memuat Vue dari CDN). Centang baris kedua, lalu ketik filter sampai baris itu keluar dari daftar —
lihat apa yang tertinggal. Untuk tugas, cukup tunjukkan `:key` di komponenmu sendiri; tidak perlu
bikin branch.

**Tambahan (tidak dinilai).** `01-kegagalan-klasik.md` — lima kegagalan port Vue; cocokkan dengan apa
yang kamu alami sendiri. `03-stasiun-react.md` — ringkasan empat stasiun gallery walk; cukup untuk
memilih satu keputusan dan memberi sticky. Kerjakan hanya kalau soal utama sudah selesai.

## Yang tidak ada di sini

Tidak ada kunci jawaban. Kalau kamu hanya menyalin kode referensi tanpa menunjuk berkas dan fungsi
milikmu, penilaian "teori umum tanpa rujukan lokal" berlaku.
