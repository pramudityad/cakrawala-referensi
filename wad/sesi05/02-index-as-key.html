SALAH :key="index"

Vue memakai ulang node DOM pada posisi yang sama. Node punya state yang tidak dikelola Vue (checked, teks yang kamu ketik) — jadi state itu tertinggal di posisinya, lalu menempel ke item yang berbeda. Persis seperti centang yang berpindah ke baris salah.

BENAR :key="item.id"

Key adalah kontrak identitas. Vue memindahkan node (beserta seluruh state DOM-nya) mengikuti item; kalau item difilter keluar, node-nya ikut hilang bersama centangannya.

Kalau kamu memakai v-model pada checkbox, bug ini tertutup — Vue ikut memperbarui properti checked, jadi yang salah kelihatan "benar". Itulah sebabnya demo ini memakai checkbox tanpa v-model: supaya yang kamu lihat adalah mekanisme reuse-nya, bukan tambalan Vue di atasnya. Kalau kamu ingin mereproduksi di proyek timmu, pakai elemen yang state-nya tidak dikelola Vue — atau perhatikan input yang sedang fokus saat list di-render ulang.
