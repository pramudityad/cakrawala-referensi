# Cakrawala — referensi kode

Referensi kode untuk mata kuliah di Universitas Cakrawala. Semua isinya **contoh**, bukan kunci
jawaban: tugas selalu dinilai dari kode mahasiswa sendiri.

Hidup di GitHub (bukan cuma ZIP di LMS) supaya demo bisa dibuka langsung di browser — tanpa unduh,
tanpa build, tanpa `npm install`.

## Isi

| Mata kuliah | Sesi | Yang dinilai | Tambahan |
| :--- | :--- | :--- | :--- |
| Web Application Development (CIK3101) | [Sesi 5](wad/sesi05/) | [demo `:key`](https://pramudityad.github.io/cakrawala-referensi/wad/sesi05/02-index-as-key.html) | [lima kegagalan port Vue](wad/sesi05/01-kegagalan-klasik.md) · [stasiun React](wad/sesi05/03-stasiun-react.md) |

## Cara pakai

Buka tautan demo di browser — itu saja. Berkas `.md` bisa dibaca langsung di GitHub.

Demo yang memuat Vue dari CDN butuh internet. Kalau kelas tanpa jaringan, berkas HTML-nya bisa
diunduh dan dibuka lokal, tetapi Vue tetap perlu diambil sekali dari jaringan.
